# Tournament_Tree

# Project Overview

In this project, I used C++ and the `string` library to implement a tournament tree that represents the results of a football competition. The project uses a `struct` to model each tournament node and an `enum` to distinguish between team nodes and match nodes. The tournament is represented as a tree structure using pointers, where each match node contains pointers to its left and right child nodes. I implemented several recursive functions to traverse the tree and analyse the tournament data. These functions determine the winning team, identify the highest score recorded in any match, and find the team that lost all of its matches. The recursive algorithms traverse the tree by visiting each match node and comparing the results stored in its child nodes, demonstrating the use of recursion, tree data structures, pointers, structs, and enums to process hierarchical data efficiently.
